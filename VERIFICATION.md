# First playable baseline — 4 October 2026

The first implementation is playable, private, and saved locally. It contains six chapters, 30 discoveries, 36 primary sources, original canvas instruments, optional original tones, validated saves, two scientific resource scenarios, two toy certificates, and Keir's gift ending. It uses six static runtime files and bundled fonts, without runtime dependencies or a build step.

**Player feedback supersedes the initial pacing assessment.** The user finished in 15:33 laboratory time with 769 qubits and 27/30 discoveries; three discoveries remained optional. Their Singular Value run took 1h33. They found this campaign too short and simple. The implementation below is the verified baseline for a deeper revision, not evidence that the current game meets their desired difficulty or length.

## Verification scope

`node --test tests/game.test.cjs`: **20 passed, 0 failed, 0 skipped**. `node tests/contrast.cjs`: **50 normal text pairs passed**, minimum ratio **4.58**. JavaScript syntax and Git whitespace checks passed. The original reference HTML remains unchanged (SHA-256 `a386c26313cb73a77ef8d03cd9cfcea363ac85355099e83af422841dad93b796`).

The compact strategy finishes with 769 active physical qubits, distance 3, and two factories; the wide strategy uses 2,049, distance 5, and one factory. Their equal completion times demonstrate that the current research economy dominates both paths. The specialist redesign must address this weakness rather than simply multiplying every price.

Browser evidence uses Chrome 150, ordinary controls, and normal imports of legally generated states. The actual full scientific workload was started in the interface from `compact-ready.json`, reached the ending, and generated a 1200×720 postcard. This is separate from a complete manual browser campaign. `browser-checks.json`, `graphics-qa.json`, `contrast.json`, and `playthroughs.json` retain detailed evidence.

The external CLI video encoder failed; the final instrument capture uses the browser's native canvas recorder, compressed to 52.07 seconds at four times playback speed. It records actual canvas output, not a continuous first playthrough. `interaction.webm` separately records the opening interface interaction. `run-postcard.png` is the game's actual exported canvas output.

Independent **AI** quantum and code reviewers accepted the reviewed source after their required corrections. Their scope does not imply a credentialed human review, experimental hardware validation, a quantum advantage demonstration, or human approval of the game's fun.
